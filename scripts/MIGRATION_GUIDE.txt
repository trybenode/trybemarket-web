└───────────────────────────────────────────────────────────────┘

  npm run migrate:lastseen

  ⚠️  This WILL update Firestore
  ✓ Safe to run multiple times
  ✓ Processes 500 users per batch

┌───────────────────────────────────────────────────────────────┐
│ WHAT IT DOES                                                   │
└───────────────────────────────────────────────────────────────┘

  1. Fetches all users from Firestore
  2. Checks if they have lastSeen field
  3. If missing → Sets to current timestamp
  4. Uses batched writes (efficient)
  5. Shows detailed summary


┌───────────────────────────────────────────────────────────────┐
│ SAFETY FEATURES                                                │
└───────────────────────────────────────────────────────────────┘

  ✓ Idempotent (safe to run multiple times)
  ✓ Batched writes (won't timeout)
  ✓ Error handling (logs errors, continues)
  ✓ Skips users who already have lastSeen


┌───────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                │
└───────────────────────────────────────────────────────────────┘

  Error: "Missing credentials"
  → Check .env file has:
    - NEXT_PUBLIC_FIREBASE_PROJECT_ID
    - FIREBASE_CLIENT_EMAIL  
    - FIREBASE_PRIVATE_KEY

  Error: "Permission denied"
  → Ensure Firebase service account has write permissions

  Some users not updated
  → Check error logs in console
  → Can safely re-run to catch missed users
